## 📌 About the Project

The **Flight Radar Simulator** is a flight tracking and management application developed using the C programming language. It simulates the basic functionality of a flight radar system by loading airport, aircraft, and flight information from local text files.

The application features an interactive **Graphical User Interface (GUI)** that allows users to view, track, and manage flights in an organized and user-friendly environment. It uses a simulated clock to monitor flight operations and calculate important flight information, including flight status, distance traveled, speed, altitude, and Estimated Time of Arrival (ETA).

This project combines core C programming concepts with practical software development techniques to create a functional flight management and simulation system.

## ✨ Features

- **Graphical User Interface (GUI):** Interactive interface for viewing and managing flight information.
- **Flight Tracking:** Monitor flight status, distance, speed, altitude, and ETA.
- **Simulated Clock:** Track flight progress using a simulated time system.
- **Airport Management:** Load and manage airport information from text files.
- **Aircraft Management:** Store and access aircraft details.
- **Flight Management:** Add and manage flight records.
- **Search Functionality:** Search for specific flights and related information.
- **Sorting:** Organize flight records based on different criteria.
- **Filtering:** Filter flights according to specific conditions.
- **Flight Statistics:** Display useful statistics about flight operations.
- **Time Zone Conversion:** Convert flight times between different time zones.
- **File Handling:** Load data from and save updated information to text files.
- **Input Validation:** Handle invalid inputs to improve program reliability.

## 📚 C Programming Concepts Implemented

During the development of this project, we applied several fundamental and advanced C programming concepts:

- **Structures (`struct`):** Used to organize airport, aircraft, and flight information.
- **Dynamic Memory Allocation:** Used to allocate and manage memory efficiently at runtime.
- **File Handling:** Used to read data from and write data to external text files.
- **Recursion:** Applied in the implementation of recursive binary search.
- **Binary Search:** Used to efficiently search for specific records.
- **Input Validation:** Ensures that user inputs are checked before processing.
- **Functions:** Divided the program into manageable and reusable modules.
- **Arrays and Pointers:** Used for data storage and memory management.

## 📂 Data Management

The simulator uses local text files to store and retrieve information about airports, aircraft, and flights.

The application reads the required information when running and allows updated records to be saved back to files. This approach provides simple and organized data management without requiring an external database or online API.
